# tdd-practice Specification

## Purpose

规定实现阶段的测试驱动纪律：先确认在哪个 seam 测、什么算好测试、怎样垂直推进、如何在压力下不找借口，以及重构属于哪一步。技艺层来自上游参考，合规层为本框架本地改编，两者同属一个技能入口，不产生第二套完成判据。

## Requirements

### Requirement: seam 预确认

系统 SHALL 要求在写测试之前先确定被测 seam 并与用户确认，未经确认的 seam 不写测试。系统 SHALL 把 seam 与模块接口契约对齐，并记录该 seam 覆盖什么、不覆盖什么。

#### Scenario: 写测试前确认 seam

- **WHEN** 任务需要新增或修改测试
- **THEN** Agent 先列出待测 seam 及各自覆盖与不覆盖的范围，取得确认后才开始写测试

#### Scenario: seam 与接口契约冲突

- **WHEN** 计划中的 seam 与模块对外接口约定不一致
- **THEN** Agent 停止写测试并报告冲突，交由设计环节处理，不在测试层私自改变接口边界

### Requirement: 好测试的判据

系统 SHALL 要求测试通过公开接口验证行为而非实现细节，并要求断言的期望值来自独立真值源（已知字面值、算例或规格），不得由被测代码同样的计算方式导出。系统 SHALL 禁止水平切片：先写全部测试再写全部实现。

#### Scenario: 期望值独立于被测代码

- **WHEN** 编写断言
- **THEN** 期望值来自规格、算例或已知字面值，不与被测实现共享同一种推导方式

#### Scenario: 检测到同义反复的断言

- **WHEN** 断言的期望值由被测代码同样的运算导出
- **THEN** Agent 判定该断言按构造永远通过，重写为独立真值源并说明原因

#### Scenario: 拒绝水平切片

- **WHEN** 出现"先写完全部测试再写全部实现"的计划
- **THEN** Agent 改为一次一个垂直切片推进，每片是一轮可运行的测试与实现

### Requirement: 合规层

系统 SHALL 保留无失败测试不写生产代码的强制要求、已知合理化说法的逐条回应、禁止行为清单与完成核对表，并 SHALL 把"先说出哪个生产改动会让这个测试失败"作为写测试前的必答项。

#### Scenario: 实现前必须看到失败

- **WHEN** 准备写生产代码
- **THEN** Agent 先运行该测试确认它因目标行为缺失而失败；测试通过则说明它测的是既有行为，需重写

#### Scenario: 遇到"这次太简单"等合理化说法

- **WHEN** Agent 出现跳过测试或事后补测试的倾向
- **THEN** Agent 按合规层的对照表逐条回应并回到测试先行的路径，不因任务简单而跳过

#### Scenario: 完成前逐项核对

- **WHEN** 准备标记任务完成
- **THEN** Agent 逐项核对完成表，包括每个新函数有测试、每个测试都先失败过、失败原因符合预期、测试保持全绿

### Requirement: 重构归属

系统 SHALL 把实现阶段的重构步限定为当前任务必要的整理（去重复、改名、抽 helper），并 SHALL 把设计级重构归入评审阶段讨论。系统 SHALL 保持实现阶段的既有步骤顺序与退出条件不变。

#### Scenario: 任务内整理留在实现阶段

- **WHEN** 实现完成后存在当前任务范围内的重复或命名问题
- **THEN** Agent 在实现阶段的整理步内处理，并保持测试全绿，不在此时改变对外接口

#### Scenario: 设计级重构归入评审阶段

- **WHEN** 发现模块边界或接口设计需要重构
- **THEN** Agent 不在实现阶段直接改动设计，而是把它记入评审阶段讨论，由评审决定是否另开变更

### Requirement: 技能替换与引用一致

系统 SHALL 以新的测试驱动技能作为实现阶段的唯一入口，下线旧入口，并更新引擎内交叉引用、阶段路由与文档计数。系统 SHALL 在清单中登记新旧分组计数，使技能总数与实际入口一致。

#### Scenario: 不再引用已下线的技能

- **WHEN** 检查引擎内技能引用、阶段路由与指南
- **THEN** 其中不再出现已下线的测试驱动技能名称，历史创作记录中的原有路径保持原样

#### Scenario: 计数一致

- **WHEN** 运行分发结构检查
- **THEN** 检查通过，且清单声明的技能总数等于实际技能入口数

#### Scenario: 上游文件保持字节一致

- **WHEN** 核对引入的上游原文
- **THEN** 每份文件的内容与上游固定提交的 blob 标识一致，本地改编内容单独成文并声明来源
